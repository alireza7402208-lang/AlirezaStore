# بازارینو | Bazarino

پلتفرم آگهی خرید و فروش با ثبت آگهی رایگان؛ نسخه MVP قابل اجرا در VS Code.

## پیش‌نیاز
- Node.js نسخه 20 یا جدیدتر
- npm

## اجرا در ویندوز / VS Code
1. فایل ZIP را Extract کن و پوشه `bazarino` را در VS Code باز کن.
2. ترمینال VS Code را باز کن.
3. دستورهای زیر را به‌ترتیب اجرا کن:

```bash
npm install
npm run install:all
```

4. برای اجرای هم‌زمان بک‌اند و فرانت‌اند:

```bash
npm run dev
```

5. سایت: http://localhost:5173
   API: http://localhost:4000/api

## حساب آزمایشی
- مدیر: `admin@bazarino.local` / `Admin123!`
- کاربر: `user@bazarino.local` / `User123!`

## امکانات فعلی
- ثبت‌نام و ورود با رمز هش‌شده و JWT
- ثبت آگهی رایگان و آپلود حداکثر ۵ تصویر
- دسته‌بندی و جست‌وجو و فیلتر شهر
- صفحه جزئیات آگهی
- علاقه‌مندی‌ها
- مدیریت و حذف آگهی‌های خود
- پیام‌رسانی پایه بین خریدار و فروشنده
- پنل مدیریت برای مشاهده و حذف آگهی‌ها
- داده‌های نمونه برای شروع

## نکات مهم
- این پروژه یک MVP آموزشی/قابل توسعه است، نه کپی کد یا سامانه داخلی شیپور.
- قبل از انتشار عمومی، حتماً `JWT_SECRET` را در فایل `server/.env` با یک مقدار طولانی و تصادفی عوض کن.
- برای استقرار واقعی، SQLite را می‌توان با PostgreSQL جایگزین کرد و تصاویر را در فضای ذخیره‌سازی ابری نگه داشت.
- برای پرداخت، پیامک OTP، نقشه، اعلان لحظه‌ای، بررسی آگهی و مقابله با کلاهبرداری باید سرویس‌های جداگانه و تنظیمات عملیاتی اضافه شوند.
- آگهی‌ها در این نسخه رایگان هستند؛ هیچ درگاه پرداختی فعال نیست.
